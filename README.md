# HEA — Arcane Arena

Prototipe game pertarungan sihir 3D **mobile-first**, bisa langsung dimainkan di browser. Dibangun dari repo yang awalnya hanya berisi `reference.mp4`.

## Menjalankan

Gunakan Node.js 22.12+ dan npm.

```bash
npm ci
npm run dev
```

Buka alamat yang ditampilkan Vite (port `5173`). Server mendengarkan di `0.0.0.0` dan menerima host preview `*.e2b.app`. Semua font, grafis, dan video dilayani dari origin yang sama; tidak membutuhkan CDN, backend, akun, atau koneksi eksternal saat bermain.

```bash
npm run build       # Pemeriksaan TypeScript + bundel produksi ke dist/
npm run preview     # Preview build produksi, port 4173
npm test            # Unit test fisika / collision / utilitas
npm run test:e2e     # Browser test; jalankan npm run dev terlebih dahulu
npm run format:check # Pemeriksaan format kode
```

Tes browser menggunakan Chromium dari paket npm di Linux, termasuk SwiftShader jika GPU tidak tersedia. Pada sistem lain, jalankan `npx playwright install chromium`, atau tentukan `BROWSER_EXECUTABLE_PATH`. `PLAYWRIGHT_BASE_URL` dapat mengganti alamat server pengujian. Screenshot/trace kegagalan, browser cache, dan `dist/` tidak masuk Git. Build `docs/` disertakan khusus untuk GitHub Pages.

## GitHub Pages

Folder **`docs/` sengaja disertakan di Git** sebagai build statis untuk metode **Deploy from a branch**. URL aset relatif, sehingga JavaScript, font, favicon, dan video tetap berjalan pada subpath `/Hea/`. File `.nojekyll` menonaktifkan pemrosesan Jekyll.

Setelah branch ini di-push:

1. Buka **Settings → Pages → Build and deployment** di repo GitHub.
2. Pilih **Source: Deploy from a branch**.
3. Pilih branch **`arena/7161cdd8-hea`**, folder **`/docs`**, lalu **Save**.
4. Tunggu deployment GitHub Pages selesai. Alamat situs: **https://hiraneku.github.io/Hea/**.

Tidak memerlukan PR atau perubahan pada `main`. Pengaturan Pages repo tidak diubah otomatis; jika masih menunjuk branch lama, situs tetap memakai versi lama sampai kamu menggantinya.

Setiap kali kode game berubah, perbarui build sebelum commit dan push:

```bash
npm ci
npm run build:pages
```

Jangan memilih folder root: `index.html` di root adalah entry pengembangan TypeScript, bukan build statis yang dapat langsung dijalankan GitHub Pages. `dist/` tetap diabaikan Git; hanya `docs/` yang disertakan untuk publikasi Pages.

## Duel v0.12 — Plaza Terbuka, Aegis Hidup, Impact Frame Kertas-Tinta & Mundur Sebelum Mantra

Delapan butir atas v0.11, semuanya dari catatan uji main dan dua video referensi (`reference.mp4` untuk cincin dash dan impact frame, `reference2.mp4` untuk perilaku Aegis). Nilai tuning ada di `src/game/layout.ts` (denah), `FLIGHT` (`src/game/config.ts`), `DUEL`/`ATTACKS`/`PROJECTILES`/`guideMissile` (`src/game/combat.ts`), `BOSS_MOTOR`/`MISSILE_RETREAT` (`src/game/BossTactics.ts`), `SHIELD_APPEAR`/`SHIELD_DISSOLVE` (`src/game/Effects.ts`), dan `src/game/ImpactFrame.ts`.

1. **Mantra kedua lebih lama, orb mengunci secukupnya, boss mundur dulu.** Mantra Pemburu: telegraph **1,2 s** (dari 1,05), salvo **2,4 s** dengan interval **0,36 s** (dari 1,75/0,28; tetap 6 tembakan × 2 orb), umur orb 5,5 s, kecepatan ramp **15 + 8·usia** sampai **28 m/s** (dari 18 + 10·usia sampai 30). Kunci sasaran dibuat sedang: orb memburu sampai **2,2 s** (dari 1,35) dan **membidik di depan tubuh yang bergerak** (lead sampai 0,54 s), tetapi hanya boleh membelok **1 rad/s** (dari 1,25) dan berkomitmen lurus pada jarak 4,5 m — hanyutan pelan 6–8 m/s di jarak 30–40 m masih tertangkap, strafe penuh 14,5 m/s lolos di semua jarak (unit `flight-combat.test.ts`). Sebelum merapal, boss **menyentak mundur**: `missileRetreat()` menambah dorongan menjauhi player sampai **33 m/s** (`BOSS_MOTOR.retreat`, di atas batas 24 m/s biasa) selama 0,55 s pertama telegraph, mereda halus sampai 0,95 s, dan tidak dilakukan bila jaraknya sudah > 46 m; ketinggian ditahan agar terbaca sebagai sentakan, bukan panjat. Pengukuran `patterns`: 17 m → 37 m dalam ±1 s, puncak 28 m/s, diam saat orb pertama lepas. Sentakan diumumkan cakram robek putih (seperti dash player, skala boss) dan semburan debu di titik lepas landas.
2. **Blok lebih besar lagi dan plaza tengah lapang.** Denah ditulis ulang di `src/game/layout.ts`: **plaza bersih berjari-jari 39 m** di pusat (tidak ada muka monolit lebih dekat dari itu; posisi awal player (0, 0, 24) dan boss ada di dalamnya), **cincin dalam 7 monolit yang ditempatkan tangan** (east/south/cover/west/slab/plate/north — fixture uji bersandar padanya lewat `beside(nama, sisi, celah)`), lalu **dua cincin luar berbenih** (8 blok pada radius 108 m lebar 44–58 m, 10 blok pada 152 m lebar 42–60 m) dengan **korridor ≥ 14 m** di antara semua blok. Tiga pita cover rendah (13 dinding 1,5–2,6 m pada radius ±51/104/146 m, hanya yang muat di celah) mengisi sela; slab tipis tetap ≤ 3,2 m agar tembusan Hempasan tidak berubah. Arena **400 × 400 m** (terrain 176 segmen, kamera far 720 m), 25 monolit + 13 cover + pelat + prisma = 38 bangunan; tinggi tidak berubah dari v0.11.
3. **Retakan Aegis diperbaiki.** Retakan per keping diganti **jaring laba-laba kaca** (`crackGeometry`): pita tipis yang menjalar dari titik hantaman dengan cabang bersudut acak berbenih, dipotong pada keping milik patch, menebal dan bertambah cabang pada hit ke-2–4, dan menjadi kisi putus pada hit ke-5 tepat sebelum pecah.
4. **Aegis tidak lagi terdorong saat dihantam.** Komponen mundur/recoil patch dihapus sama sekali; patch diam di tempat, hanya kilat keping, percikan di bidang, dan retakan yang bertambah yang menandai hantaman (sesuai `reference2.mp4`).
5. **Muncul dan lenyapnya Aegis dikerjakan sungguhan.** Patch tidak lagi "pop" seperti hantu: keping-keping **terwujud satu per satu** dari titik ancaman ke tepi selama **0,14 s** (`SHIELD_APPEAR`; prediksi patch dimajukan ke 0,24 s sebelum kontak agar sempat utuh saat bolt tiba), dan saat masa pakainya habis keping **menyusut menjadi titik** dalam **0,16 s** (`SHIELD_DISSOLVE`) sambil melepaskan **kepulan uap kelabu dan kerlip** per keping — pecah lima hit tetap seketika.
6. **Hempasan lebih cepat melesat.** Kecepatan lontar: bolt api 36 → **44** m/s, orb 60 → **72**, Hempasan Surya 122 → **150**, benih pusaran 80 → **98**, Nova pada boss 112 → **138** (`DUEL.novaLaunch`); batas gabungan lontaran player 140 → 175 m/s. Freeze 0,15 s + slow-motion tidak berubah, sehingga perbedaannya terasa tepat saat pelepasan.
7. **Dash terbang mendorong kecepatan sesudahnya dan membuka dengan cakram robek.** Setelah dash, motor terbang mendapat **+65 % kecepatan** (`FLIGHT.boost`) yang meluruh selama **1,5 s** (`boostDuration`): 52 m/s pada +0,07 s → 22 m/s pada +0,5 s → 14,5 m/s pada +1,6 s, kick FOV mengikuti. Tepat pada titik lepas, **cakram putih pipih** tegak lurus arah dash (`Effects.dashRing`, shader): mengembang 2,2 → 4,5 m dalam 0,2 s sementara bagian dalamnya terkikis menjadi **cincin bergerigi** dengan lipatan biru-kelabu pucat, sesuai `reference.mp4`; pita cahaya tubuh **menebal sampai 3,4×** selama dorongan masih cepat lalu menipis kembali. Diagnostik `dashMotion.boost`.
8. **Impact frame mendekati referensi.** Kilat DOM `#impact-flash` dihapus; diganti **pass pasca-proses `ImpactShader`** (`src/game/ImpactFrame.ts`, setelah OutputPass, ruang layar) yang berjalan dalam **waktu nyata** selama freeze: (A) **1 frame kertas putih** dengan siluet hitam dua-nada (ambang luminansi), **tepi diarsir tinta** (Sobel → arsiran layar), dan jari-jari hitam tipis dari titik kontak; (B) **0,1 s negatif** — kertas hitam, siluet putih, **baji garis kecepatan putih meruncing** dari titik kontak dengan zona bersih di tengah; (A') kertas putih lagi 0,1 s; lalu memudar 0,07 s. Warna jenuh (avatar merah, glyph, api) dipertahankan. Titik kontak diproyeksikan dari posisi hantaman dunia (`uCenter`). Pemicu: setiap kontak berat (freeze/slow) dan benturan tubuh ke dunia, dibatasi `DUEL.impactInterval` 0,65 s dan dimatikan di menu; **Efek Dikurangi** hanya memainkan satu ketukan kertas 0,16 s tanpa negatif. Composer kini selalu RenderPass → Bloom (dimatikan pada kualitas Ringan) → OutputPass → ImpactFrame, dan jalur `renderer.render` langsung dipakai saat bloom mati dan tidak ada frame aktif. Diagnostik `impactFrame` {active, phase, elapsed}.

Pengujian: 126 unit (12 berkas), e2e `arena.spec.ts` 31 skenario mobile/desktop + 9 golden desktop (golden diperbarui untuk denah baru). Probe `.cache/*.mjs` yang dipakai selama pengerjaan tidak disertakan.

## Duel v0.11 — Boss Raksasa, Ragdoll Bersendi, Dash Burst & Serangan Jarak Jauh

Tujuh butir atas v0.10, semuanya dari catatan uji main. Nilai tuning ada di `ARENA`/`WORLD_SCALE`/`FOOTPRINT_SCALE`/`BOSS` (`src/game/config.ts`), `AirDash` (`src/game/motion.ts`), `BOSS_MOTOR` (`src/game/BossTactics.ts`), dan `src/game/Ragdoll.ts`.

1. **Boss lebih besar.** Seluruh konstruk digambar pada skala **1,45×** (`BOSS.scale`): radius tabrakan 1,48 → **2,15 m**, jarak pusat-ke-dasar 2,05 → **2,97 m**, hover terendah 3,7 m. Semua yang bergantung pada ukurannya ikut diskalakan — jari-jari tabrakan proyektil player, bayangan kontak, tinggi tumpuan saat rebah, margin NavGraph (`BOSS.radius + 1,2`), jari-jari sapuan rute dan carrot sudut, puing kekalahan — dan gerbang api satelit tumbuh 1,25× (`GATE_SCALE`) agar proporsional.
2. **Ragdoll bersendi (`src/game/Ragdoll.ts`).** Hempasan berat tidak lagi melempar satu balok kaku: begitu Hempasan Surya mengenai player, avatar diganti **figur Verlet 15 titik** (panggul, dada, kepala, dua lengan dengan siku, dua kaki dengan lutut) yang dihubungkan tulang kaku dan **batas sendi** (lutut/siku tidak melipat terbalik, kepala tidak masuk dada), 4 sub-langkah × 6 iterasi per frame, bertabrakan dengan tanah berlekuk dan blok arena dengan gesekan. Panggulnya **ditambat** ke akar fisika yang sudah ada (`BodyTumble`), sehingga peluncuran, tembusan dinding, alur seretan dan kamera tidak berubah, sementara lengan, kaki dan kepala mencambuk, terseret di belakang tubuh dan terkulai sendiri (pelepasan awal mengikuti arah hantaman + putaran sudut tubuh, tangan/kaki diberi lemparan acak kecil agar tak ada dua jatuh yang sama). Saat bangkit, seluruh figur **dikumpulkan kembali ke pose berdiri** (blend 0,3 s, `BodyTumble.humanRise`) lalu avatar mengambil alih; jejak cahaya tubuh dimatikan selama terseret di tanah. Pecahan boss ikut **bergetar dan terlempar** mengikuti putaran saat ia sendiri rebah. Diagnostik `ragdoll.playerFigure` {span, lowest, pelvis, nodes}, `playerFigureSpawns/Contacts`; unit `ragdoll.test.ts`; golden `ragdoll-drag`.
3. **Boss tidak pernah bungkam di mode jalan kaki.** Akar masalahnya: `firingLane()` menuntut lintasan bebas tanah sepanjang radius penuh proyektil, padahal terhadap target di tanah bola 1,25 m selalu "menyentuh tanah" sebelum sampai, sehingga boss rendah terus mencari posisi dan diam. Kini tiap jenis proyektil punya **toleransi kena-tanah** (`GROUND_MISS`: api 0,8 m, orb 1 m, Hempasan/benih pusaran 3,2 m) dan Hempasan yang meledak di tanah dekat player **melontarkannya lewat ledakan** (`hammerSplash`, radius 3,6 m, 9–20 HP dan hempasan ragdoll yang melemah ke tepi — inilah hukuman boss terhadap player yang berdiri). Bila jalur serangan yang sedang dipilih tertutup, boss **mengalihkan** ke serangan apa pun yang korridornya muat (`redirect`; jalur bersih dikalahkan jalur tembus), bukan menunggu. Pengukuran `walk-live` 40 s: blokir terpanjang < 4,5 s (sebelumnya puluhan detik diam), > 20 lemparan.
4. **Blok dinding lebih lebar, bukan lebih tinggi.** Denah kini digambar pada tiga skala terpisah: posisi **1,5×** (`WORLD_SCALE`), tapak (lebar × tebal) **1,69×** (`FOOTPRINT_SCALE`), tinggi tetap **1,3×** (`HEIGHT_SCALE`, sama dengan v0.10). Monolit tengah lebar 18–38 m, cincin pada radius 105 m dan 158 m, arena **380 × 380 m** (terrain 408 m, 168 segmen, kabut dan langit-langit 70 m tetap); slab tipis tetap ≤ 3,2 m agar tembusan Hempasan tidak berubah; 44 bangunan. Fixture uji yang bersandar pada dinding tertentu dipindah ke muka baru (`wall`, `pierce-player`, `cover`, `sight-thin`).
5. **Dash kelas AAA.** Kurva kecepatan: naik hampir seketika (45 ms) ke **37 m/s**, ditahan 0,1 s, lalu meluncur meluruh pangkat 1,7 selama 0,33 s — tubuh menyentak lalu mengendap, bukan meluncur dengan kecepatan tetap. **Input buffer 0,18 s** (tekanan sedikit terlalu dini saat cooldown/rebah tetap dieksekusi). Visual: **afterimage** tubuh (salinan aditif yang memudar 0,26 s, tiap 32 ms) plus garis cahaya yang tertarik ke belakang, glyph arah pada dada, kick FOV +7°, whoosh dua lapis. **Jendela tembus 0,26 s** (`invulnerableFor`): proyektil boss yang seharusnya mengenai tubuh dalam jendela itu **lewat begitu saja** dan dihitung sebagai **ELAKAN SEMPURNA** — slow-motion 0,5 s, cincin cahaya, lonceng dua nada, +20 energi, cooldown dash dipangkas ke 0,4 s, dan keterangan di HUD. Diagnostik `perfectDodges`, `particles.afterimages`.
6. **Serangan jarak jauh selama player terlihat.** `BossTactics.step()` menerima bendera pandang: boss yang melihat player dari > 30 m saat telegraph/serangan **menahan posisinya** (motor ×0,25, tarikan jarak dimatikan) dan merapal dari sana — Rentetan Api dari 55–60 m, orb pemburu, Hempasan, benih pusaran — lalu merapat kembali hanya pada fase pemulihan. Kipas Rentetan Api **menyempit mengikuti jarak** (`focus = clamp(30/jarak, 0,4, 1)`) sehingga aliran jarak jauh tetap mengurung target. Unit `motion-tactics.test.ts`; e2e: boss di (62, 5, 26) menembak dari > 40 m terhadap player di (0, 0, 24).
7. **Mekanik rapalan dirombak.** Tubuh batu boss berada pada pivot sendiri: ia **merunduk ke belakang** selama muatan (Hempasan 0,19 rad, lainnya 0,11) dan **menyentak maju** 0,38 m pada pelepasan (`snap`, meluruh 3,2/s); **sigil kedua** yang berputar berlawanan menyala di dalam glyph utama dan membesar bersama muatan; keempat pecahan mengatup rapat saat mengisi dan terlempar keluar saat melepas. Rentetan Api: tiap gerbang satelit yang jalurnya tertutup dinding/tanah **berpindah ke slot cincin terdekat yang bersih** (`gateOriginFor`), dan setiap bolt **menyala di dalam gerbangnya** (pelat kilat 0,14 s di depan cincin). Orb pemburu meninggalkan port dengan **busur mengembang ke luar dan ke atas** (17 m/s) sebelum berbelok menukik, sehingga salvo mekar dulu lalu mengerucut; tiap port mengeluarkan percikan. Hempasan Surya: 0,3 s terakhir telegraph **menggambar garis tembak** ke titik kunci, glyph ganda di moncong, dan **recoil 7,5 m/s** mendorong boss mundur saat melempar. Golden `boss-cast`.

Pengujian: 124 unit (12 berkas), e2e `arena.spec.ts` 31 skenario mobile/desktop + 9 golden desktop. Fixture baru: `walk-live`, `ragdoll-ground`, `splash`; harness `observe(at, look)` memasang kamera pengamat untuk tangkapan layar jarak dekat.

## Duel v0.10 — Arena 340 m, Boss Lebih Gesit, Bekas Gosong & Mix Audio

Sebelas perubahan atas v0.9, dari catatan uji main dan empat butir daftar saran yang disetujui (#4 audio seretan + mix, #5 tuning kontrol sentuh, #6 anggaran partikel adaptif, #9 bekas gosong bolt api). Nilai tuning ada di `ARENA`/`WORLD_SCALE` (`src/game/config.ts`), `ATTACKS`/`PROJECTILES` (`src/game/combat.ts`), `BOSS_MOTOR` (`src/game/BossTactics.ts`), `STICK`/`LOOK` (`src/game/Controls.ts`).

1. **Hit pada Aegis tanpa denyut dan tanpa gelombang biru.** Riak keping, cipratan datar, dan cincin/gelombang melingkar per hit dihapus seluruhnya (bukan sekadar diredam). Yang tersisa pada setiap blok: proyektil menggepeng di permukaan, **satu kilat singkat pada keping yang terkena** (`cellFlash`/`looseFlash`, 90 ms), percikan yang memantul di bidang patch, satu dorongan mundur tunggal tanpa pantulan balik berulang, dan retakan yang bertambah per hit. Efek pecah pada hit kelima tidak berubah.
2. **Dinding lebih besar lagi, arena lebih luas lagi.** Seluruh denah greybox (cluster tengah, dua cincin, pita cover rendah, prisma miring, skyline) digambar pada skala **1,3×** (`WORLD_SCALE`): monolit tengah kini lebar 14–29 m, tebal 13–20 m, tinggi sampai 55 m; cincin pada radius 91 m dan 137 m; slab tipis tetap 2,4–2,6 m agar mekanik tembus Hempasan tidak berubah. Arena **340 × 340 m** (dari 260), terrain 368 m dengan 152 segmen (sel ±1,1 m di tengah), langit-langit terbang **70 m** (dari 56), kabut 150–440 m. Fixture uji dan koordinat e2e yang bersandar pada dinding tertentu ikut diskalakan (`at()` di `TestScenarios.ts`).
3. **Audio seretan dan penyeimbangan mix (#4).** `Audio.ts` ditulis ulang di atas satu **bus kompresor** (threshold −16 dB, rasio 4:1) dengan volume master ×0,6: seretan tubuh di tanah kini bersuara — loop gesekan per aktor (noise tersaring yang nadanya mengikuti kecepatan, boss 1,3× lebih berat) yang menyala saat terseret dan meluruh saat berhenti (`audio.scrape`); bunyi blok shield/hit dibatasi 50–60 ms per jenis dan saling meredam dalam jendela 0,5 s sehingga rentetan 54 bolt tidak lagi menjadi lengkingan; peluncuran, telegraph, dan ledakan diberi headroom relatif terhadap bolt biasa.
4. **Tuning kontrol sentuh (#5).** Joystick: dead zone radial **14 %**, kurva respons pangkat 1,45 (`stickResponse()`), defleksi penuh pada 36 % lebar joystick (±48 px) sehingga ibu jari tidak perlu menjangkau tepi, dan pusat stik mengikuti titik sentuh pertama sampai 20 % lebar; layar pandang: gain 1,25 yang naik sampai 2,35 pada sapuan cepat (flick). Tombol aksi **56 px** (sihir) dan **84 px** (Aegis/dash) dengan halo sentuh 9 px — 52/76 px pada layar sempit — joystick 132/120/112/110 px menurut lebar layar; area sentuh tidak lagi saling bertumpuk pada 390 × 844.
5. **Anggaran partikel adaptif (#6).** `adaptDensity()` menyesuaikan kepadatan emisi dari FPS terukur (sampel ±0,75 s): turun cepat (−0,15/sampel) di bawah 30 fps menuju 0,3, setengah kepadatan di pita 30–42 fps, naik perlahan (+0,05/sampel) di atasnya; emisi diskalakan `density^0,75`, pool partikel menyusut sampai lantai 120 (mode Ringan maksimum 0,45 / 198), kepadatan tidak pernah di bawah 0,3 agar benturan tetap terbaca. Dua detik pertama dan fixture simulasi manual dikecualikan. Diagnostik `particles.density`, `particles.budget`.
6. **Bekas gosong bolt api (#9).** Api yang mencapai tanah meninggalkan **tanda hangus**: cakram gelap bergerigi (`src/game/Scorches.ts`, pool 48, kisi 4 × 4 yang digelar di atas kontur tanah, blending multiply dengan premultiplied alpha agar menggelapkan permukaan apa pun di bawahnya) radius ±1,15 m untuk bolt dan 1,7 m untuk orb pemburu, bertahan 6–8 s lalu memutih pada 40 % terakhir umurnya, ditambah kepulan asap pendek. Hanya Hempasan yang menggali kawah; api dan orb hanya menghanguskan. Fixture `scorch`, diagnostik `particles.scorches`.
7. **Rentetan Api lebih panjang dan lebih menyebar.** Durasi **5,6 s** (dari 4,2), **54 bolt** (dari 40) tetap berinterval 0,1 s dalam 14 paket; kipas sebaran dilebarkan menjadi ±7,5° menyamping dan +4,9°/−3° vertikal (`salvoSpread`) sehingga rentetan menyapu jalur, bukan mengebor satu titik.
8. **Pola gerak boss lebih cepat.** Batas motor terbang naik 25 % (`BOSS_MOTOR`: jelajah 15, rute 20, pemulihan 19, maksimum 24 m/s), gain menuju waypoint 1,25/1,6, pelumasan kecepatan 5,2, dwell manuver 1,5–2,9 s. Dua perbaikan navigasi menyertainya: **manuver kini sadar pandang** — setiap waypoint strafe/flank/press diuji masih punya jalur tembak ke player dan dapat dicapai lurus (`sighted` callback; bila tidak, coba arah sebaliknya, busur lebih pendek, lalu bearing saat ini), sehingga boss tidak lagi meninggalkan posisi bersih untuk terbang kembali ke balik monolit; dan begitu pandang didapat di tengah rute, kunci rute dilepas agar kontrol jarak menariknya masuk dari sudut yang baru diintipnya. Biaya detour vertikal pada steering lokal dinaikkan 1,5× agar boss menyelinap lewat sudut monolit alih-alih memanjat 40 m. Fixture `far-north`: boss dari (120, 127) mencapai jarak < 40 m dengan pandang bersih dan menyerang pada detik ke-8–12.
9. **Semua proyektil boss lebih cepat.** Bolt api 30 → **36** m/s, orb pemburu 25 → **30** (ramp 18 + 10·usia), Hempasan Surya 31 → **37**, benih pusaran 26 → **31**. Radius collision dan ukuran visual tidak berubah.
10. **Berdiri seketika setelah seretan.** Tidak ada lagi jeda "pingsan": ambang bangkit `BodyTumble.riseSpeed` dinaikkan ke **6,5 m/s** (dari 4) sehingga transisi berdiri dimulai ketika seretan masih sedikit bergerak dan selesai bersamaan dengan berhentinya tubuh; penghitung `settled` dihapus. Kontak tanah ragdoll kini **menjepret** ke permukaan setelah pendaratan pertama (`moveBody`) — pada terrain berlekuk kontak sebelumnya putus-putus sehingga tubuh dianggap masih "di udara" dan rebah beberapa detik. Pengukuran: boss berdiri ±3,0 s setelah hempasan Nova (sebelumnya 5–6 s), player ±2,4 s setelah Hempasan Surya.
11. **Pengujian.** Unit baru untuk tanda hangus (drape, pudar, daur ulang slot), kepadatan adaptif, dan waypoint sadar pandang (118 unit). E2e: fixture `scorch` (6 tanda, 0 kawah, memudar dalam 10 s), `far-north` dengan pandang disampel beberapa detik, sudut pandang golden `arena-overview` dinaikkan ke 68 m; ketujuh golden dibuat ulang untuk denah 1,3×.

## Duel v0.9 — Benturan Nyata pada Aegis, Alur Seretan & Pusaran Surya

Lima perubahan atas v0.8, semuanya berangkat dari catatan uji main. Nilai tuning ada di `DUEL` / `ATTACKS` / `PROJECTILES` (`src/game/combat.ts`).

1. **Patch Aegis pecah dengan cara yang khas, setelah lima hit.** Durabilitas `shieldPatchHits` 3 → **5**. Setiap hit menaikkan muatan keping (glow dan isi bertambah per hit) dan sejak hit kedua menggoreskan **retakan** di sekitar titik hantam yang ikut bergerak bersama keping. Pada hit kelima patch tidak sekadar hilang: selama satu ketukan seluruh keping mengunci putih dengan retakannya menyala, lalu **keping heksagonal terkelupas satu per satu dalam gelombang dari titik hantam** (jeda 0,09–0,25 s menurut jarak), terbang menyebar di bidang patch sambil berputar dan menyusut dengan jejak sian, sebuah **gelombang kejut berbentuk heksagon** (bukan lingkaran) merambat keluar dua lapis, dan garis luar patch tertinggal sebagai bayangan selama 0,45 s. Diagnostik `particles.shards`, `shieldEchoes[].shattered`.
2. **Jejak seretan menjadi alur tanah, bukan decal.** Decal goresan bertitik dihapus seluruhnya. Tubuh yang terseret kini **membelah tanah**: satu mesh strip dinamis (`src/game/Furrows.ts`) menggelar penampang 7 titik per 0,3 m — **parit gelap di tengah dan dua gundukan tanah terangkat di kiri-kanannya, lurus mengikuti arah seretan** (lebar ±1 m, tinggi gundukan 0,14–0,4 m menurut kecepatan) — ditambah bongkahan tanah cokelat yang terlempar ke samping, debu dan kerikil. Satu seretan = satu alur menerus (langkah panjang dibagi otomatis), jeda > 0,3 s atau lompatan memulai alur baru; gundukan melesak dan warnanya kembali ke warna tanah selama 3 s di akhir umurnya (7–10 s). Telegraph 1,25 s: bara di moncong boss **mengecil** menjadi butir merah gelap sementara cincin muatannya menguncup dan percikan tersedot ke glyph (kebalikan dari gembungnya Hempasan). Lalu sebuah benih gelap meluncur (26 m/s) ke titik prediksi posisi player dan **menambat 2,5 m sebelum tubuh** (atau di dinding pertama) sebagai sumur gravitasi: piringan akresi mendatar dengan bibir oranye yang menandai radius inti (3,2 m), piringan rune yang berputar berlawanan, dan titik putih panas di jantungnya. Selama **1,7 s** (`vortexPull`) sumur menarik tubuh — percepatan 30 m/s² di inti, melemah linear sampai radius 22 m, ditumpuk sebagai vektor `pull` tersendiri di atas motor terbang sehingga thrust melawannya dan dash memutusnya — dan **setiap partikel lepas** (percikan, debu, bongkahan) ikut terseret berpusar. Kemudian sumur **meledak**: kilatan, gelombang kejut heksagonal, cincin **14 bolt api mendatar** ke segala arah, kawah bila dekat tanah; tubuh yang masih di dalam radius inti terkena hit berat (24 HP, hempasan ragdoll dengan jeda beku/slow-motion). Jawabannya bukan kabur lurus (punggung adalah titik buta Aegis) melainkan **naik atau menukik** keluar dari bidang cincin, atau dash menjauh sebelum ledakan. Boss kebal terhadap sumurnya sendiri. Audio `vortex` (dengung naik) dan `detonate`. Pengukuran: player diam dengan Aegis ON yang pada v0.8 bertahan > 90 s kini **kalah pada detik ke-45** (dua pusaran); player yang bergerak dapat lolos dengan satu dash.
4. **Patch tidak menumpuk: disusun seperti kepingan puzzle.** `ShieldPatchRegistry.place()` menempatkan tiap patch baru pada **kisi heksagon bersama** (cluster) dengan patch berdiri yang searah (normal·n > 0,72) dan seukuran di sekitarnya: keping dipasang pada anchor kosong terdekat dari titik intersepsi, lebih memilih anchor yang **bersentuhan sisi** dengan patch lain, dan tak pernah digeser lebih dari 70 % radius bloknya agar tembakan yang memicunya tetap mendarat. Hasilnya kipas bolt membangun **cangkang berubin** rapat tanpa dua keping saling menutupi (`patchTiling.overlaps` selalu 0). Lintasan yang jauh berbeda mendirikan kisi sendiri. Diagnostik `patchTiling` {clusters, joined, overlaps}, `shieldPatches[].cluster/anchor`.
5. **Proyektil benar-benar menghantam permukaan patch.** Pada v0.8 proyektil dihapus saat prediksi (beberapa milimeter/frame sebelum menyentuh) dan hanya efeknya yang dimainkan. Kini prediksi hanya **mendirikan** patch di titik lintasan memotong cangkang (`shieldIntercept().point`, memperhitungkan gerak tubuh) dan proyektil **terus terbang** (`claim`) sampai kepalanya menyentuh cakram patch (`patchBlocks` kini kontak bidang/cakram dengan offset moncong, api 0,36 m). Pada kontak itulah hit dihitung (`blocked`, `hits`): **tubuh proyektil tertinggal di permukaan, menggepeng dan melebar lalu memudar** (0,16 s; 0,26 s untuk Hempasan), cipratan datar menyebar di bidang patch, percikan memantul di sepanjang permukaan, patch **terdorong mundur** 0,12–0,22 m (0,22 untuk Hempasan) dan memantul balik sambil beriak, dan bunyi blok dibedakan per jenis proyektil. Claim yang tak lagi berada di lintasan (tubuh berbelok) dilepas dan patch baru dipasang di sebelahnya; bila tembakan tetap lolos sampai tubuh dalam cakupan Aegis, satu keping darurat muncul rapat di tubuh dan menyerapnya di sana. Patch lama yang masih berdiri menyerap proyektil berikutnya dengan cara yang sama. Diagnostik `particles.shieldImpacts`, `shots[]` (proyektil masih terdaftar sampai benar-benar menyentuh).

Putaran tanah dibatasi agar tidak berputar terus seperti roda. Begitu seretan melambat, transisi berdiri dimulai langsung dan selesai sekitar 220 ms, tanpa jeda pingsan tambahan. Orientasi balok menentukan tinggi tumpuannya agar pose rebah tidak melayang di atas tanah. Ragdoll yang melayang 0,85 s tanpa menyentuh apa pun menegakkan diri di udara (v0.7); benturan menyetel ulang penghitung itu. Kamera tidak ikut berguling bersama tubuh. Kontak menampilkan percikan lokal; benturan keras berikutnya dengan lingkungan menghasilkan puing, debu, jeda benturan dan impact frame hitam-putih. Serangan biasa yang tidak mengenai lingkungan tidak memalsukan impact frame.
- **Kerusakan nyata:** bagian balok yang hancur dihapus dari mesh dan collision. Tanah berlekuk secara permanen selama duel, dan collision menggunakan segitiga permukaan yang sama. Restart mengembalikan arena, boss, HP, energi, dan semua cooldown.
- Tiga sihir player: **Bara** (api dengan bantuan bidik), **Prisma** (sinar cyan instan), **Nova** (ledakan dan knockback berat).
- Dash udara memakai kurva akselerasi 60 ms, puncak 90 ms, lalu coast 350 ms. Arah dash dapat dibelokkan perlahan; boost ditambahkan ke gerak terbang dan turun kembali ke kecepatan normal tanpa stop mendadak. Kekebalan hanya pada 230 ms awal, bukan seluruh coast/cooldown. Hover dan kontrol ketinggian, regenerasi energi, serta pemulihan HP setelah sembilan detik tanpa terkena serangan.
- Multitouch, fokus boss opsional, layout portrait/landscape, pause, restart, demo real-time, panduan, dan video referensi asli.
- Audio WebAudio prosedural; kualitas, sensitivitas, volume, serta **Efek nyaman** untuk menonaktifkan impact frame dan mengurangi guncangan. Jeda kontak tetap berlaku agar aturan hempasan konsisten. Rekor waktu kemenangan dan preferensi disimpan lokal.

## Hubungan dengan referensi

Video sekitar tujuh detik di `reference.mp4` menjadi acuan arena greybox, player merah dengan pita putih, boss terbang gelap dengan lingkaran emas, tembakan api, laser cyan, perisai heksagonal, puing dan impact frame. Versi ini mengikuti koreksi pengguna: **player vs satu boss**, shield otomatis, dan knockback ke lingkungan destruktibel.

`reference2.mp4` (11,75 detik, unggahan pengguna) juga telah diperiksa: bagian sekitar 5,2–8,2 detik menjadi acuan kepingan hex dan bolt api. Keduanya tersedia lewat pemilih di viewer referensi. Bentuk dan tempo yang terlihat direkonstruksi; detail yang tertutup efek/perspektif tetap membutuhkan tuning, bukan klaim salinan identik frame-per-frame.

Model tetap mengikuti gaya blockout, bukan karakter humanoid. Respons player dibuat lebih menyerupai tubuh yang terlempar/terseret; bukan mengganti model merah dengan manusia. Durasi jejak, damage, kecepatan, jarak boss dan urutan serangan tidak dapat diukur pasti dari cuplikan; nilainya merupakan tuning awal yang dapat diubah, bukan klaim replika 100%.

## Teknologi dan struktur

- Three.js + TypeScript + Vite; font dan aset dibundel lokal.
- `src/game/Game.ts`: simulasi duel, chase camera, knockback, projectile CCD, spell dan hasil duel.
- `src/game/Boss.ts`: satu model boss terbang, glyph, telegraph dan presentasi visual.
- `src/game/combat.ts`: Aegis directional, contact pause, pola boss, radius collision, spread dan panduan misil; tuning `DUEL` / `ATTACKS` / `PROJECTILES`.
- `src/game/flight.ts`, `src/game/motion.ts`, `src/game/config.ts`: flight/camera spring, dash envelope, pelepasan impuls, ragdoll rotasi, hover dan batas arena.
- `src/game/BossTactics.ts`: waypoint/taktik ketinggian dan posisi lingkaran satelit yang diacak secara deterministik.
- `src/game/BossNavigation.ts`: graf visibilitas sudut bangunan, A\*, pemilihan vantage dan steering boss (v0.8).
- `src/game/ShieldPatches.ts`: registri patch Aegis — kisi heksagon bersama agar patch berdampingan seperti puzzle, kontak cakram, durabilitas 5 hit, lubang sudut setelah pecah (v0.8–0.9).
- `src/game/Furrows.ts`: alur seretan — strip tanah dinamis dengan parit dan gundukan kiri-kanan yang mengikuti arah seretan (v0.9).
- `src/game/Scorches.ts`: tanda hangus — pool cakram gelap bergerigi yang digelar di atas kontur tanah dan memudar (v0.10).
- `src/game/TestScenarios.ts`, `src/game/terrainGrid.ts`: fixture QA deklaratif dan pemetaan grid terrain adaptif (v0.8).
- `src/game/destruction.ts`: sel balok destruktibel, collider berlubang, dan bentuk kawah.
- `src/game/World.ts`: arena prosedural, mesh pecahan, deformasi tanah dan bayangan kontak.
- `src/game/ShieldVisual.ts`: potongan polyhex yang tersambung dengan jumlah/susunan keping berbeda, geometri prisma heksagon dan retakan untuk efek pecah.
- `src/game/AttackSight.ts`: pemeriksaan jalur tembak non-mutatif, ketebalan material dan kemampuan serangan.
- `src/game/Effects.ts`: particle pool, instanced debris/bongkahan, debu, ribbon, glyph, beam, benturan dan pecahan shield, atraktor pusaran.
- `src/game/Controls.ts`, `Audio.ts`, `math.ts`: input multitouch (dead zone, kurva respons, flick), suara prosedural pada bus kompresor dengan loop gesekan seretan, dan collision.
- `src/main.ts`, `src/style.css`, `src/duel.css`: HUD duel, menu dan dialog responsif.

**Kualitas dan batas simulasi:** mode Tinggi memakai shadow map dan bloom, DPR maksimal 2. Ringan menonaktifkan keduanya, membatasi DPR ke 1, serta mengurangi partikel. Otomatis memakai Ringan untuk perangkat sentuh dan dapat menurunkan kualitas desktop. Jika beberapa sampel FPS tetap rendah, resolusi render otomatis dapat turun sampai 75%; HUD tetap dirender pada resolusi CSS. Fisika memakai substep; tab yang tersendat tidak membuat proyektil/hempasan menembus arena. Render berhenti saat pause/hasil duel kecuali diperlukan pembaruan tampilan.

Bangunan utama memakai sel voxel; collider bangunan miring masih merupakan pendekatan bounding box. Prisma dekoratif memakai collider tetap. Puing bergerak merupakan efek terpool, bukan rigid-body yang saling menumpuk. Kawah dibatasi 24 bentuk per duel untuk menjaga biaya komputasi; kerusakan lama tidak dihapus diam-diam. Tidak ada simulasi keruntuhan struktural seluruh bangunan. Ragdoll memakai dinamika translasi/rotasi balok, tumpuan berorientasi, penyerapan benturan dan gesekan tanpa restitusi tanah dengan collider konservatif; bukan kerangka humanoid multi-sendi. Penetrasi menggunakan ray/material-span pada collider voxel, termasuk pendekatan bounding box pada bangunan miring.

Font Inter dan Barlow Condensed didistribusikan melalui `@fontsource` beserta lisensi OFL. Selain video referensi, aset visual dibuat secara prosedural dalam kode.

## Status Android

Ini adalah **prototipe web untuk diuji di mobile**, belum APK/native Android. Pengujian Chromium/emulasi sentuh bukan benchmark HP Android nyata; belum ada klaim FPS untuk perangkat tertentu. Perlu uji latensi sentuh, panas/baterai, rasio layar dan WebGL pada perangkat sasaran sebelum membungkusnya dengan Capacitor atau memindahkan gameplay ke engine native. Belum ada multiplayer atau level lain.
